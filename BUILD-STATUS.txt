Margherita 1.0.0 (1.0.0) pre-release

README release draft preserved with the requested Buy Me a Coffee URL update.
About and app menus include user-initiated browser support links.
GPL-3.0 license, bundled license copy and build/cache exclusions added.
First launch uses onboardingCompletedV2. Redownloads retain preferences.
Reset for testing after quitting:
  defaults delete com.oscar.margherita onboardingCompletedV2

Safety sweep includes bounded subprocess output, cancellation cleanup,
validated staged audio publishing, image pixel/PDF page limits, safer
Unicode/case collision handling, background file moves, and malformed
string-preference fallback defaults.

Optional Sparkle CLT binary integration uses the official pinned universal
framework. Download/import failures explicitly omit the updater. The feed
and public key are intentionally placeholders; updates remain disabled
until configured. See RELEASE-UPDATES.md for setup and distribution steps.

Watch folders persist security-scoped bookmarks and format profiles, wait
for stable files, use FSEvents plus reconciliation, retry failed inputs,
and write to the excluded .Margherita Outputs folder. Originals stay by
default. Opt-in Trash uses identity-checked recovery staging. See
Tests/WATCH_FOLDERS_SAFETY.md for limits and recovery instructions if present.

Styled DMG packaging renders native 1x/2x backgrounds and a Retina TIFF,
sets the pizza volume icon and uses Finder automation for window layout.
Actual PNG reference assets were rendered and visually inspected on Linux.
Make DMG.command must run after Build Margherita.command on a logged-in Mac.
See DMG-INSTALLER.md for the Automation permission and visual test checklist.

41 Swift app files pass tree-sitter syntax parsing and lexical symbol audit.
Native macOS SDK compilation, code signing, Finder/Retina rendering,
FSEvents delivery, security-scoped bookmark runtime, Vision/AVFoundation,
Office automation and an actual Sparkle upgrade are NOT verified here.
No built .app or .dmg is claimed by this source package.
Final full Python suite: 227 tests, 218 passed, 9 macOS-only skipped.
Run completed after all release changes; no failures. Linux/mock tests
do not substitute for the Mac release checklist.
